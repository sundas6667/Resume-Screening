# 🚀 TalentLens AI – AI-Powered Resume Screening & Candidate Ranking System

TalentLens AI is an intelligent Resume Screening and Candidate Ranking platform that helps recruiters analyze multiple resumes, compare them against a job description, rank candidates using explainable AI, and generate professional reports.

Designed with a lightweight yet powerful architecture, the system combines NLP-inspired techniques, TF-IDF semantic matching, configurable scoring, and a Groq-powered AI assistant to streamline the hiring process.

---

## ✨ Features

### 📄 Resume Processing
- Upload multiple PDF resumes simultaneously
- Automatic resume parsing and structured information extraction
- Graceful handling of corrupted, encrypted, or scanned PDFs
- Candidate profile generation

### 🎯 AI-Powered Matching
- TF-IDF + Cosine Similarity matching
- Intelligent skill matching using a 217+ skill taxonomy
- Experience analysis
- Education evaluation
- Certification recognition
- Project assessment

### 🏆 Candidate Ranking
- Explainable weighted ranking system
- Fully configurable scoring
- Detailed score breakdown
- Candidate comparison
- Recruiter-friendly insights

Default scoring:

| Category | Weight |
|----------|---------|
| Skills | 35% |
| Experience | 30% |
| Education | 15% |
| Certifications | 10% |
| Projects | 10% |

---

## 🤖 AI HR Assistant

Powered by **Groq (Llama 3.1 8B Instant)**

The AI Assistant can answer recruiter questions such as:

- Who is the best candidate?
- Compare the top candidates
- Which skills are missing?
- Why is Candidate A ranked higher?
- Recommend candidates for a specific role

The assistant only uses structured candidate data generated by the system and never invents candidate information.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/RAYYAN-369/Resume-Screening.git

cd Resume-Screening
```

### Create Virtual Environment

Windows

```bash
python -m venv venv

venv\Scripts\activate
```

Linux / macOS

```bash
python3 -m venv venv

source venv/bin/activate
```

### Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```

Open:

```
http://localhost:8501
```
